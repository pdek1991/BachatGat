Upload a CSV file to add multiple users at once to any group.

Download Sample CSV Format for Users

CSV Requirements:

  • Must contain headers: `user_name`, `group_id` (or `group_name`).
  • Optional headers: `is_admin` (0 or 1), `status` (e.g., 'active', 'inactive').
  • `group_id` refers to the numeric ID of the group. If `group_name` is used, the group must exist by that name.
  • If both `group_id` and `group_name` are provided, `group_id` takes precedence.
  • Users will be added only if they don't already exist in the specified group.
