Upload a CSV file containing various transaction types (contributions, loan repayments, interest payments, loan disbursements).

CSV Columns:
`user_name` (exact name of user), `type` (e.g., `contribution`, `loan_repayment`, `interest_paid`, `loan_disbursement`), `amount`, `date` (YYYY-MM-DD)
`is_cash_payment` (0 or 1, optional, default 0), `is_paid` (0 or 1, optional, default 1)
`loan_id` (Required for `loan_repayment` and `interest_paid`, leave blank for `contribution`/`loan_disbursement`)
`new_loan_interest_rate` (Optional, **for `loan_disbursement` only**, overrides group default rate)

Important: All transactions in the uploaded CSV must belong to the currently selected group (Group ID: **{{ selected_group_id }}**).
